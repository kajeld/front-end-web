# Inspired

I found this interactive website called [The Sound of Love](https://thesoundof.love/). I realized that I normally interact with websites that are either very polished or serve a specific function in my everyday life, so I wanted to find something that felt more “useless,” although I don’t really think this website is. When you click anywhere on the screen, a new song plays and a comment from that song’s YouTube section appears. I actually noticed that the comments seem to be hardcoded because at first I thought the comment would change if I got the same song again. What really caught my attention was the simplicity of the design and how such a simple concept can still feel so effective and interesting. I love stories, so seeing real people’s reactions to songs and the personal experiences they connected to them was really beautiful to me. The website was made by Chia Amisola in 2022 and updated in 2024. I’m especially curious about what happens technically during the transition between clicking the screen and the next song and comment appearing. There are a few musical notes that appear during the buffer, including one around wherever you clicked that then fades away. I’d like to understand how those notes are randomly generated and positioned. I’m also curious about the comments themselves. If you wanted the website to pull a completely random comment from a song, would you need to create your own database, or is there an existing database or API you could pull from?
