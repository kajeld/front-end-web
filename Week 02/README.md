# Navigation Example 


For this week’s example of interesting website navigation, I chose [Special Offer, Inc](https://www.specialoffer.inc)., a creative tech and design studio. Their website makes navigating through projects feel interactive rather than just using a traditional menu. When you open the site, projects flash across the screen, and the cursor controls where you go next: hovering on the left shows an arrow to go back, while hovering on the right lets you move forward. Clicking in the center opens more information and images about the project. I also like how the top and bottom navigation stays visible throughout the site, even when the colors change to match each project, creating a consistent structure while still letting each project have its own visual identity.
